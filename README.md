# Altrium Recruitment Management System

A full-stack recruitment management platform developed as a university project for managing the recruitment process from job vacancy creation and candidate applications to application tracking, evaluation, interview scheduling and administration.

## Project Overview

Altrium was developed to provide a centralised recruitment platform for candidates, recruitment staff and administrators.

The system supports the main stages of the recruitment workflow while providing functionality for vacancy management, candidate applications, recruitment evaluation, interview scheduling, notifications and administration.
