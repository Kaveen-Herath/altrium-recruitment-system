## Altrium Recruitment Management System

A full-stack recruitment management platform developed as a university
project for managing the recruitment process from job vacancy creation
through candidate application, evaluation, interviews and hiring.

## Project Overview

Altrium was developed to provide a centralised recruitment platform for
candidates, recruitment staff and administrators.

The system supports candidate recruitment workflows while providing
management functionality for vacancies, applications, interviews,
notifications and administration.

## My Contribution

I worked as a Developer and was primarily responsible for the frontend
and user-interface development of the system.

My responsibilities included:

- Designing and developing responsive user interfaces
- Implementing candidate and administrative workflows
- Connecting frontend interfaces with backend APIs
- Integrating database functionality
- Implementing authentication and application functionality
- Developing job search and filtering features
- Implementing saved jobs and application tracking
- Supporting interview scheduling and notifications
- Performing debugging and automated testing using Playwright

## Key Features

- Job vacancy browsing and search
- Job filtering
- Saved jobs
- Candidate applications
- Application progress tracking
- Application status history
- Candidate notifications
- Interview scheduling
- Calendar integration
- Vacancy management
- Applicant management
- Candidate evaluation
- Administrative dashboard
- Authentication and role-based access
